# Challenges Versioning & Maintenance
![Git](https://img.shields.io/badge/Git-F05032?style=for-the-badge&logo=git&logoColor=white)
![Fedora](https://img.shields.io/badge/Fedora-51921C?style=for-the-badge&logo=fedora&logoColor=white)

Ce dépôt documente ma maîtrise des workflows Git avancés, de la gestion des conflits à l'intégration de l'IA responsable.

## 🛠 Compétences démontrées
- **Workflows Professionnels** : Feature Branching, Pull Requests, Code Review.
- **Maintenance** : Cherry-picking de correctifs, tags de release (SemVer).
- **IA Responsable** : Traçabilité du code généré par IA et revue humaine.
- **Résolution de conflits** : Gestion manuelle des divergences complexes.

## 🚀 Structure du projet
- `config_validator.py` : Validateur de configuration (Feature assistée par IA).
- `ai-review.md` : Documentation de la traçabilité IA.
- `docs/` : Documentation technique sur le versioning.
